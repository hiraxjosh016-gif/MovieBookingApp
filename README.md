This is a simple program that helps one to do a movie booking right with there gadgets 
This is important because it saves one from having to go physically to wherever the cinemas for a booking.
It has three files which are complied together and in the end make it a complete program.
It rotates on the movie that’s to be shown and has attributes such as name, ticket price, duration and much more.
The seat manager is one that’s showing the number of seats, ones available and ones that are taken and the location for easy and comfort booking.
