This project is a Java-based Movie Ticket Booking System developed using Object-Oriented Programming principles and Java Swing for the graphical user interface.
This simple app saves one from having to go physically to wherever the cinemas for a booking.
It has three class files which are compiled for execution as a complete program.
It rotates on the movie that’s to be shown with its attributes. Each movie holding its own plan.
The seat manager class is one that’s showing the number of seats, ones available and ones that are taken and the location for easy and comfort booking.
BookingMovie.java-This class stores movie information such as the movie title, duration, start time, and ticket price
MovieTicketBooking.java-This is the main application class that provides the graphical user interface and handles movie selection, seat booking, payment selection, and booking confirmation.
